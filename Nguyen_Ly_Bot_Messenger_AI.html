🤖 Nguyên Lý Hoạt Động — Bot Messenger AI "Bí Quyết Giặt Sấy Dân Sinh"

Tổng Quan: 3 Thành Phần Chính

👤 Khách nhắn tin  →  📱 Facebook (Webhook)  →  🖥️ Server (Railway)  →  🧠 Gemini AI  →  Trả lời khách

Bước 1: Khách Nhắn Tin → Facebook Gửi Cho Bot

Khi khách nhắn "bọt nhiều có sạch không" trên Messenger:

  1. Facebook không giữ tin — nó lập tức gửi sang server của mình
  2. Gửi bằng HTTP POST request đến URL webhook đã đăng ký
  3. URL đó là: https://biquyetgiatsay-bot-production.up.railway.app
// Facebook gửi cái này cho server mình:
{
  "sender": {"id": "27848080704863601"},
  "message": {"text": "bọt nhiều có sạch không"}
}
💡 Lưu ý: Đây là lý do cần **webhook URL cố định** — Facebook phải biết gửi tin đi đâu. Trước đây dùng Cloudflare tunnel (URL đổi liên tục), giờ dùng Railway (URL vĩnh viễn).

Bước 2: Server Nhận Tin → Xử Lý

File auto_reply_bot.py là "bộ điều khiển":

📊 Luồng xử lý tin nhắn:
📩 Nhận tin
↓
Gõ 1/2/3? → 📄 Gửi link cẩm nang
Câu khác? → 🧠 Gọi Gemini AI
↓
✅ Chia tin bằng ||| → Gửi từng tin
❌ Nếu lỗi → Retry 3s hoặc fallback

Công nghệ dùng: - Flask — web framework Python, nhận HTTP request từ Facebook - Gunicorn — chạy Flask ở production (2 workers xử lý đồng thời) - Threading — xử lý AI ở background thread, tránh Facebook timeout

Bước 3: Gemini AI — "Bộ Não" Của Bot

File ai_engine.py làm 3 việc:

3A. Nạp kiến thức (~160KB text)

data/CAM_NANG_NUOC_GIAT_HOAN_CHINH.md  →  73,991 ký tự
data/Cam_nang_nuoc_xa_vai.md            →  84,133 ký tự

Bot đọc toàn bộ 2 file này khi khởi động → nhét vào System Prompt → Gemini "thuộc lòng" hết.

3B. System Prompt — "Tính cách" của bot

Đây là phần quan trọng nhất, quyết định bot nói kiểu gì:

Quy tắc Mục đích
"Bạn là NGƯỜI THẬT, KHÔNG phải AI" Giọng tự nhiên, đời thường
"Mỗi lượt 2-3 tin ngắn, dùng ||| ngăn cách" Chat như người thật, không gộp 1 đoạn dài
"Dùng ạ, nha, hen, á, nè" Giọng Việt Nam thân thiện
"Khi khách có nhu cầu → chốt SĐT" Thu lead cho đội sale
"Nhắc nước xả thơm lâu sau sấy" Quảng bá sản phẩm nhẹ nhàng

3C. Gọi API Gemini

# Đơn giản thế này:
response = gemini.generate_content(
    model="gemini-3.1-flash-lite",     # Model nhanh, ổn định
    contents="bọt nhiều có sạch không", # Câu hỏi của khách
    system_instruction=SYSTEM_PROMPT,   # 160KB kiến thức + quy tắc
)
# → AI trả lời dựa trên kiến thức + quy tắc đã nạp

Bước 4: Gửi Tin Về Cho Khách

# AI trả lời:
# "Ủa cái này hay|||Bọt không liên quan sạch đâu|||Tiệm dùng máy gì?"

# Bot chia thành 3 tin riêng:
tin_1 = "Ủa cái này hay"        → gửi → đợi 1s
tin_2 = "Bọt không liên quan..." → gửi → đợi 1s  
tin_3 = "Tiệm dùng máy gì?"    → gửi

Gửi qua Facebook Send API:

POST https://graph.facebook.com/v21.0/me/messages
Authorization: PAGE_ACCESS_TOKEN
Body: {"recipient": {"id": "..."}, "message": {"text": "..."}}
